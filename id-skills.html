IERhub.com - Idea to First Sale

The Market Challenge

The Texas Dept. of Licensing & Regulation (TDLR) requires continuing education across 38+ regulated trades, representing a target market of nearly 1 million working professionals in Texas.

Since maintaining these licenses legally requires annual, biannual, or multi-year continuing education, it creates a potential recurring revenue stream. Currently nine different courses are scheduled to be developed, hosted, approved by TDLR, and then marketed.

Step 2 - How a Course Is Made

Build · Pipeline

Automated Curriculum AI Pipeline

Built a multi-agent AI workflow that turns electrical-safety codes (NEC®, NFPA 70E®) into finished Moodle courses.

  • Source data (RAG): Indexed the source codes into a retrieval (RAG) pipeline so the AI answers from cited text, not from model memory.
  • Running the agents: A set of AI agents runs in order to chunk the content, set objectives, draft lessons, and write assessments.
  • Quality gates: A three-part check (fact-check, copyright, QA) reviews every course. Anything it flags, such as a wrong claim or a compliance problem, goes back for a rewrite before the course ships.

Step 4 - Delivery Platform - Moodle LMS

Deliver · Platform

Delivery Platform & Compliance Workflow (TX4HRCE)

Set up course delivery and state reporting on Moodle, turning the state's rules into automated workflows.

  • Enrollment: Automated sign-up, where Stripe handles payment and enrollment ties to the learner's state license number.
  • Compliance rules: Built in the state's requirements (a 50-minute seat-time minimum per module and a 12-month block on repeat credit), both checked before a certificate is issued.
  • Data and reporting: Set up a PostgreSQL database (on DigitalOcean) for learner records, automated the 7-day completion report to the Texas Department of Licensing and Regulation (TDLR), and gave auditors a read-only dashboard with the required 4-year record retention.
